📚 这个 GitHub 项目，9000+ Star，收录 24000+ 电子书

你有没有过这种感觉——

想读一本书，打开 Kindle 书架空空如也；打开某读书 App，热门榜单全是总裁文和霸道总裁；去某当搜，标价几十块一本，买了又觉得肉疼。

说实话，一年到头开个读书会员，加起来也好几百了。

最近发现了一个 GitHub 项目，彻底改变了我的看书方式。

ebook-treasure-chest，一个开源电子书资源库，9000 多星，目前收录中文电子书 24,071 本，覆盖 1000 个分类，文学、历史、科普、管理、经济、投资、心理……全都有。

🔍 它能做什么？

1. 海量资源，一站搞定

主流读书平台（帆书、微信读书、京东读书、喜马拉雅）上的热门书，这里基本都有。重点是——每本书都提供 epub + mobi + azw3 三种格式，Kindle、手机、平板随便看，不挑设备。

2. 分类齐全，找书不费劲

来看看目前的资源体量：

分类数量
文学2711 本
历史1748 本
科普743 本
管理/经济/职场持续更新
投资/创业/心理学持续更新
技术手册/推理/经典持续更新

1000 个分类，基本涵盖了一个人成长路上会看的所有书。

3. 在线搜索，秒出结果

不想一页页翻？直接上搜索页，输入书名或作者名，多关键词搜索，秒出结果。懒得打字 `Ctrl+F` 翻页也行，体验很顺。

💡 使用场景

  • Kindle 用户：直接下载 azw3 格式，推送到设备，完美适配
  • 手机/平板阅读：epub 格式，iBooks、多看、静读天下都能用
  • 整理癖：下载到本地管理，不依赖任何平台会员
  • 学习党：技术手册、专业书籍，找起来比百度文库靠谱太多
